🔴 Critical Bugs

These are broken/inconsistent right now. A faculty member opening the app or repo will spot them immediately.

1. Precision@K numbers are wrongCritical
evaluate.py's is_relevant() scores relevance by keyword overlap between query & caption. But CLIP's whole point is semantic retrieval without keyword overlap — so CLIP gets punished and scores look terrible (5%). The Master WPR claims 62–84%.
Fix: Use a proper ground-truth relevance set (map each test query → its true Flickr8k image filename), then a hit = top-K contains the relevant image. This will make CLIP score realistically high (matching the WPR story).
2. requirements.txt incompleteCritical
Missing imports that the app actually uses: open_clip_torch, rank_bm25, scikit-learn, plotly. On a fresh machine / cloud, pip install -r requirements.txt then streamlit run app.py → ImportError crash.
Fix: Add the four packages with pinned versions.
3. CLIP install is non-standardCritical
model.py does import clip (OpenAI CLIP from GitHub), but model_comparison.py & train.py use open_clip. Two different CLIP libraries with different APIs. README install is brittle.
Fix: Standardize on open_clip_torch for everything, OR document both install steps clearly. For cloud deploy, open_clip_torch is far safer.
